# 易数 - 梅花易数数字起卦

一款基于传统梅花易数的数字起卦工具，纯前端实现，无需后端服务。

## 功能特点

### 双模式起卦

| 模式 | 用途 | 解读重点 |
|------|------|----------|
| **寻物** | 寻找丢失物品 | 方位分析、物品可能位置 |
| **问世** | 询问事情吉凶 | 卦象解读、运势分析 |

### 起卦方式

输入三个数字（0-999）进行起卦：
- **第一个数字**：确定上卦
- **第二个数字**：确定下卦
- **第三个数字**：确定动爻（选填，不填则自动计算）

### 结果展示

- **本卦**：当前状态，含六爻解读
- **互卦**：发展过程
- **变卦**：最终结果
- **体用分析**：五行生克关系
- **三卦综观**：综合解读与建议

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 选择模式（寻物/问世）
3. 输入数字和问题（选填）
4. 点击"起卦"查看结果

## 寻物模式说明

在寻物模式下，系统会根据体用关系分析：

- **主要方位**：物品最可能出现的方向
- **次要方位**：次有可能的方向
- **卦象提示**：根据八卦象征（天=高处、水=水边等）给出具体位置建议
- **寻找难度**：基于五行生克判断寻找难易程度

### 八卦方位对照

| 卦象 | 方位 | 象征物 |
|------|------|--------|
| 乾 | 西北 | 高处、金属旁、圆形物体 |
| 兑 | 西 | 低洼处、水边、破损处 |
| 离 | 南 | 明亮处、电器旁、文书堆 |
| 震 | 东 | 震动处、木质家具旁 |
| 巽 | 东南 | 通风处、窗边、缝隙中 |
| 坎 | 北 | 水边、暗处、容器内 |
| 艮 | 东北 | 高处、土石旁、柜子上 |
| 坤 | 西南 | 低处、容器内、角落 |

## 注意事项

### 关于起卦

1. **心诚则灵**：起卦时应心念专一，想着所问之事
2. **数字选择**：可随意想三个数字，也可用手机时间、车牌号等
3. **一事一卦**：同一件事不宜反复起卦
4. **动爻说明**：第三个数字可不填，系统会根据时辰自动计算

### 关于解读

1. **仅供参考**：卦象解读仅供参考，不可全信
2. **理性判断**：重大决策应结合实际情况理性分析
3. **方位指引**：寻物模式的方位仅为参考，需结合实际环境
4. **卦辞来源**：卦辞、爻辞基于传统易经文本

### 技术说明

- 纯前端实现（HTML + CSS + JavaScript）
- 无需联网，本地运行
- 建议使用现代浏览器（Chrome、Firefox、Edge 等）
